ABOUT THE PROJECT

A simple digital healthcare appointment system

CareConnect is a front-end SDC project designed to reduce the difficulty of manually scheduling healthcare appointments. It provides separate User and Admin modules with JavaScript-based navigation and Local Storage.

Problem solved

  • Reduces manual appointment booking.
  • Allows users to manage their bookings.
  • Allows admins to manage doctors and appointments.
  • Provides a clear dashboard for both modules.
