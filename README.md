# CareConnect — Healthcare Appointment System

## SDC Project Review-1

### Problem Statement
Manual healthcare appointment scheduling can be time-consuming for patients and staff. Patients may need to call or visit a clinic to find available doctors and appointment times. The project provides a simple web-based frontend for discovering doctors and managing appointments.

### Business System
**Healthcare Appointment Management System**

### Modules
1. **Admin Module**
   - Admin login
   - Dashboard statistics
   - View/manage appointments
   - Cancel appointments
   - View registered users
   - View doctors

2. **User/Patient Module**
   - Signup and login
   - Dashboard
   - Browse doctors
   - Book appointment
   - View appointments
   - Cancel appointment
   - Profile

### Technologies
- HTML5
- CSS3
- JavaScript
- Local Storage
- CSS Grid and Flexbox

No frameworks, backend, database, PHP, React, Bootstrap, or other technologies are required.

## How to Run
1. Download/clone this project.
2. Open `index.html` in a browser.
3. For the easiest local development experience, use VS Code + Live Server if available. The application itself only uses HTML/CSS/JS.
